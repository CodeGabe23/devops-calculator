# Calculator - requirements (v1)
1. Add two numbers.
2. Subtract two numbers.
3. Multiply two numbers.
4. Divide two numbers when the divisor is not zero.
5. Display the result to the user.

the calculator is complete when it performs addition, subtraction,
multiplication and division on valid inputs and displays the correct result.
Examples:
- Add 2 and 3 -> 5.
- Divide 8 by 2 -> 4.

Make sure to check for division by zero error
