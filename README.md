# A Python 3 calculator used from the Terminal

## What it will do
Add, subtract, multiply and divide two numbers; display the result.

## Prerequisites
Have python3 installed
Have python's pytest library 

## How to run and test it
1. Enter testing venv via: source /opt/python-venv/sccm-4910/bin/activate
2. run ./check.sh
3. run ./run.sh

Expect to see 5 tests succeeded.

## The program described
Enter the first number, operator (+ - * /), then second number.
The program prints the result

## How to stop it 
currently, the way to stop it is to just press ctrl+c
